# CC0 production music — 13 original instrumental tracks, free for any use

Thirteen original instrumental tracks by **AERIS MUSIC**, released into the public domain under
**CC0 1.0**. Use them in anything — YouTube, podcasts, ads, games, client work, commercial
projects — with **no attribution required and no license fee**.

They are here because the alternative most people reach for is "royalty free" library music that
still carries attribution terms, per-project limits, or Content ID claims. These have none of that:
you cannot get a copyright claim on a track that is in the public domain. Every track is composed
from scratch (no samples, no borrowed melodies), so there is no third-party rights issue.
