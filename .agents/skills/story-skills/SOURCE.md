Downloaded from the pinned GitHub archive. The `genre-craft` and `scene-craft`
packages, their references, and the shared conventions reference are retained
unmodified. No upstream CLI, dependency installer, or executable script was run.
The existing `../novel-writing/` package is retained alongside these packages.

Applied references:

- `genre-craft/references/mystery-fair-play.md`: visible clue plants, separate
  motive/means/opportunity, delayed significance, and resolved red herrings.
- `genre-craft/references/thriller.md`: unequal information, narrowing options,
  and consequences that follow a player's investigation.
- `scene-craft/references/dialogue-subtext.md`: stated versus hidden objectives,
  concessions under pressure, and distinct voices without repeated catchphrases.
- `scene-craft/references/openings.md`: an immediate task interrupted by a death,
  prompt character anchors, and instability carried by concrete evidence.

The wholly new case **The Quiet Sentence** is an original application of these
Story Skills methods. It is not copied from an upstream example. **The Ninth
Photograph** combines the previously authored novel-writing cases **The Ninth
Bell** and **The House Below the Tide**. The five other retained cases preserve
their novel-writing provenance. See `docs/story-catalog.md` for the public list.

This repository stores game canon in `data/solo_scenarios.json`, rather than a
standalone Story CLI manuscript project. Clue/source links, fixed chronology,
character counts, private/public boundaries, and red-herring payoffs are checked
against that existing schema. Manuscript-project scaffolds and registries are
therefore not installed into the game.
